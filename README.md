# Frying Pan Animation

A simple frying pan animation built using HTML, CSS and a little JavaScript.

![Frying Pan Animation Screenshot](./Screenshot%202024-08-23%20094708.png)

Overview

This repository contains a lightweight, self-contained animation of a frying pan and contents using only web technologies. It's intended as a small visual demo you can open in any modern browser.

Features

- Smooth CSS-driven animation
- Pure front-end implementation (no build steps or dependencies)
- Small, easy-to-read source files for learning and customization

Languages

- CSS — 73.5%
- HTML — 26.5%

Get started

1. Clone or download this repository.
2. Open `index.html` in your browser (double-click or use your editor's Live Server).

That's it — no build tools required.

Files

- `index.html` — markup and minimal JavaScript to initialize the demo
- `style.css` — animation and visual styles
- `Screenshot 2024-08-23 094708.png` — demo screenshot included in this README

Customize

- Tweak `style.css` to change animation speed, colors, and shapes.
- Edit `index.html` if you'd like to add more scene elements or controls.
